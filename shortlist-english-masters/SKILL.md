# Shortlist English-Taught Master's Programs

## 1. Get the applicant profile

Respond in English. Use the information already supplied and ask once for the missing essentials.

- Bachelor's subject and degree title, awarding country and institution, completed or expected completion date, and cumulative grade with its scale and direction. Ask for the best possible and lowest passing grade if conversion might be required.
- A redacted transcript or a module list with credits and credit system, completion status, and grades where available. A summary is enough to begin. Ask for module descriptions or other evidence when specific rules make them necessary. Ask the user to remove names, student numbers, addresses, and document identifiers before sharing.
- Target intake semester and academic year (for example, winter 2027/28 or summer 2028), preferred master's fields or tracks, and target countries or regions. Separate firm filters from preferences. If the user has no geographic preference, agree on a practical search scope with the user. For a fixed university or program list, use it as the scope unless the user requests wider discovery.
- Maximum tuition, currency and basis (per semester, year, or degree), whether it is a hard cap, and whether compulsory fees count toward it. Ask for the relevant fee or application category when it affects the result, such as EU/EEA versus non-EU/EEA or domestic versus international. Ask what English proof or exemption the applicant already holds, including the test date and relevant scores when available.

## 2. Discover and verify one program at a time

Read [admissions-review.md](references/admissions-review.md) before verifying candidates and [run-and-workbook.md](references/run-and-workbook.md) before starting the search.

1. Record the search scope, term, preferences and minimal academic profile in a local run folder. Discover candidates in small batches using official directories, university catalogs, and targeted searches. Use directories to find leads and add each candidate to the queue once per university, degree/track, campus and intake. Save discovery coverage after each batch.
2. Use the available browser to open each program's official pages one by one and follow their links to governing documents. If an interactive browser is unavailable, use web tools that fetch full pages and PDFs. Check the official program, admissions rules and ordinances, relevant annexes and amendments, language of instruction, tuition and compulsory fees, intake dates, deadlines, and actual application route. Inspect each complete applicable admissions source in manageable sections and record precise citations. Search snippets and directory summaries are discovery aids.
3. Compare each mandatory rule against the applicant's evidence. Confirm an entirely English-taught path through all compulsory parts of the degree. Include a candidate only when all verifiable eligibility requirements and hard filters are supported and the application and fee details are complete. Distinguish routine application steps and competitive selection from missing qualifications. Save the decision and concise evidence after each source or candidate. Mark unmet criteria privately as excluded and unresolved criteria as unverified.
4. Continue through the agreed scope. When a missing applicant fact could unlock plausible candidates, consolidate the evidence request and keep verifying independent candidates. Before concluding, chase material gaps through official sources, close out each reviewed case, and record what the search covered and any limits.

## 3. Produce the workbook

- Export one Excel workbook with the qualified shortlist, rule-by-rule admissions evidence, governing documents reviewed, and a search summary. Include official program and direct application links, term and applicable deadlines, tuition and compulsory fees, and exactly 150 words per program explaining where the applicant's studies align with the curriculum. Cite the specific curriculum used and ground every academic claim in the applicant's record.
- Run the bundled exporter and reopen the workbook to verify the shortlist, links, and evidence. When the completed review yields no confirmed matches, return the same workbook with an empty shortlist and a plain explanation on the summary tab. Never include the names of excluded or unverified candidates in the workbook.
- Keep source excerpts, transcripts, the full queue, and resolved candidates out of working context. Carry forward only the current program, a small pending batch, and open evidence questions. Resume from disk after context compaction. If the environment must stop before the defined scope is finished, label any export partial and preserve the checkpoint for resumption.
